# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-12-24

### Added
- Initial release of Smart Glass Card
- Glassmorphism design with blur effects
- Support for toggle and slider controls
- 6 color themes (amber, blue, emerald, violet, cyan, rose)
- TypeScript support with full type definitions
- Built with Lit 3.x for optimal performance
- Touch-friendly interface with press feedback
- Responsive design for all screen sizes
- Auto color detection based on entity type
- Compatible with Home Assistant 2025.12+
